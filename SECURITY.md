# Security and privacy reports

For a vulnerability that could expose private information or permit unauthorized actions, use [GitHub's private vulnerability report](https://github.com/jjthibau/pf2e-hidden-enemy-spells/security/advisories/new). Please do not post campaign data or working exploits in a public issue.

For ordinary display or spell-sequencing bugs, use the public issue template with a synthetic reproduction.

The current0.1.x release line receives fixes. Compatibility is verified only for the versions stated in the manifest and README.

The module uses Foundry's normal GM whispers and document permissions. It is a gameplay concealment feature, not a replacement for Foundry's trust model or a guarantee against inspecting client data. Mechanically necessary traits and cast rank are retained in anonymous spell records so PF2e can calculate saves correctly.
